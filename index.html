04Objetivos
Objetivo general

Desarrollar un sistema de punto de venta web para la papelería JAYA, con registro de ventas, gastos y entradas de mercancía, actualización inmediata de existencias, consulta remota de la información y control de acceso de los usuarios por parte del administrador, para la mejora de la confiabilidad de la información y de la supervisión de las operaciones.

04Objetivos específicos

Desarrollo de módulos

3

Desarrollar el módulo de ventas

Mediante

el registro de cada operación con descuento inmediato de las existencias

Para

la prevención de diferencias entre los registros y el inventario físico

4

Desarrollar el módulo de inventario

Mediante

el registro de productos, la consulta de existencias y alertas de reabastecimiento

Para

la disponibilidad oportuna de los productos solicitados por los clientes

5

Desarrollar el módulo de gastos

Mediante

el registro de egresos de dos tipos: de proveedor, con captura de los productos recibidos para su entrada al inventario, y generales, como luz o internet, con captura de un solo monto

Para

el control de las salidas de dinero y la actualización de las existencias
